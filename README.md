# Farm Data Use Agreement Template

## Overview

This repository contains a template for a **Farm Data Use Agreement** designed for research projects that use data provided by farmers or agricultural organizations.

The agreement describes how farm data may be:

- Collected
- Stored
- Protected
- Analyzed
- Shared
- Reused for future research

The template also incorporates the **FAIR data principles**, which aim to make research data **Findable, Accessible, Interoperable, and Reusable** while protecting confidential farm information.

## FAIR Data Principles

The agreement follows the four FAIR principles.

### Findable

Data should have clear file names, metadata, variable descriptions, and documentation so that researchers can easily locate and understand the data.

### Accessible

Access to the data should be clearly defined.

Sensitive or identifiable farm data do not need to be publicly available and may be restricted to authorized researchers.

### Interoperable

Data should use commonly accepted formats and standards whenever possible.

Examples include:

- CSV files
- Consistent variable names
- Standard measurement units
- Standard date formats
- Documented category codes
- Data dictionaries

### Reusable

Data sources, cleaning procedures, transformations, and analytical methods should be documented so that the data and analyses can be understood and reproduced in future research.

Future reuse of the data should follow the permissions provided by the farmer or data provider.

---

## Data Privacy

FAIR data management does **not** mean that all farm data must be made publicly available.

Confidential information should be protected whenever possible.

Examples include:

- Farmer names
- Farm names
- Addresses
- Contact information
- Exact farm locations
- Sensitive production information
- Financial information

Identifiable information should be removed or de-identified before data are shared publicly or included in publications.

---

## Use of Artificial Intelligence and Machine Learning

Farm data may be used for statistical analysis, machine learning, or artificial intelligence when appropriate.

Possible applications include:

- Predicting animal performance
- Predicting nutrient requirements
- Predicting feed efficiency
- Predicting animal health outcomes
- Predicting food or product quality
- Evaluating environmental or management factors
- Developing farm decision-support tools

Predictive models should be properly validated and documented.

Researchers should also clearly report model limitations and uncertainty.

## How to Use This Template

1. Open `Farm_Data_Use_Agreement.md`.
2. Replace the bracketed information such as `[Project Title]`, `[Name]`, and `[Institution]`.
3. Modify the agreement based on the type of farm data being collected.
4. Review the agreement with the farmer or data provider.
5. Clearly define how the data can be accessed, shared, and reused.
6. Make sure that confidential farm information is protected.
7. Review applicable institutional, ethical, and legal requirements before using the agreement in a real research project.
